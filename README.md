# Aviones Distribuidos

Proyecto monorepo con frontend React y backend Nest.js.

## Estructura
- `frontend`: aplicación React con Vite
- `backend`: API Nest.js con un endpoint que usa la librería `dijkstrajs`

## Pasos
1. `npm install`
2. `npm run start:backend`
3. `npm run start:frontend`

## Endpoints
- Backend: `http://localhost:3001/shortest-path?from=A&to=F`
